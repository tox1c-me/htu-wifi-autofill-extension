# htu-wifi-autofill-extension

适用于河南师范大学校园网认证的自动填充插件，支持宿舍 WiFi 和教学楼 WiFi 自动填充登录功能，实现全自动登录。

## 功能特性

- 🏫 **教学区认证** — 支持 `10.10.36.2` Dr.COM 哆点系统自动填充
- 🏠 **宿舍区认证** — 支持 `10.101.2.194` 自动填充，含运营商选择（移动/联通/电信/教职公/资源/直连）
- 🔒 **独立配置** — 两个区域账号密码分别保存，互不干扰
- ⚡ **自动登录** — 填充后自动点击登录按钮，无需手动操作
- 🎨 **精美动画** — 开屏启动动画，体验流畅
- 📦 **本地存储** — 数据完全本地保存，安全无忧

## 安装方法

1. 下载本插件，解压到文件夹
2. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/`
3. 开启右上角「**开发者模式**」
4. 点击「**加载已解压的扩展程序**」
5. 选择插件文件夹，完成安装

## 使用说明

### 首次使用

1. 在浏览器右上角单击插件图标启动
2. 分别切换到「🏫 教学区」和「🏠 宿舍区」选项卡
3. 填写对应的账号和密码
4. 宿舍区用户请根据实际情况选择运营商（直连用户选"无"）
5. 点击「💾 保存」

> 💡 数据完全本地保存，不用担心隐私泄露～

### 日常使用

连接校园网后，认证页面会自动弹出并填充账号密码，实现全自动登录。无需任何手动操作。

如需手动触发，点击插件弹窗中的「⚡ 立即填充」按钮即可。

## 认证地址

| 区域 | 地址 | 说明 |
|------|------|------|
| 教学区 | `10.10.36.2` | 教学楼/办公区 Dr.COM 系统 |
| 宿舍区 | `10.101.2.194` | 宿舍区认证系统 |

## 技术栈

- Chrome Extension Manifest V3
- `chrome.storage.sync` 本地存储
- 原生 JavaScript

## 安全性

插件所有数据均通过 Chrome 内置的 `chrome.storage.sync` API 存储，数据仅保存在用户浏览器本地，不会上传至任何第三方服务器。
