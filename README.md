# htu-wifi-autofill-extension

河南师范大学校园网自动认证 Chrome 扩展，支持教学区、宿舍区和教师区。

## 版本

- `htuwifi-v4`：历史版本，使用 `chrome.storage.sync`。
- `htuwifi-v4.1`：当前维护版本，使用 `chrome.storage.local`，并兼容迁移旧版配置。

## v4.1.0 功能

- 根据认证页面参数自动识别教学区、宿舍区和教师区；
- 分别保存三个区域的账号配置；
- 自动填充账号密码并可选择自动提交；
- 支持运营商选择、认证页快捷跳转和退出校园网；
- 使用 Manifest V3 和原生 JavaScript；
- 配置保存在当前浏览器的 `chrome.storage.local` 中。

## 安装

1. 下载 `htuwifi-v4.1` 目录或 Release 压缩包；
2. 打开 `chrome://extensions/`；
3. 开启“开发者模式”；
4. 选择“加载已解压的扩展程序”；
5. 选择 `htuwifi-v4.1` 目录。

## 使用

1. 打开扩展弹窗；
2. 分别填写需要使用的区域账号和密码；
3. 选择运营商和是否自动提交；
4. 点击保存；
5. 连接校园网后打开认证页面，扩展会自动填充。

配置由浏览器本地保存，扩展本身不向第三方服务器上传配置。请仅在自己的校园网账号和授权环境中使用。
