# htu-wifi-autofill-extension

河南师范大学校园网自动认证 Chrome 扩展，支持教学区、宿舍区和教师区。

## 主要功能

- 根据认证页面参数自动识别区域；
- 分别保存教学区、宿舍区和教师区配置；
- 自动填充账号密码并可选择自动提交；
- 支持运营商选择、认证页面快捷跳转和退出校园网；
- 使用 Manifest V3，配置保存在当前浏览器的 `chrome.storage.local` 中。

## 安装

1. 下载发布包并解压；
2. 打开 `chrome://extensions/`；
3. 开启“开发者模式”；
4. 选择“加载已解压的扩展程序”；
5. 选择本目录。

## 使用

1. 打开扩展弹窗；
2. 分别填写需要使用的区域账号和密码；
3. 选择运营商和是否自动提交；
4. 点击保存；
5. 连接校园网后打开认证页面，扩展会自动填充。

配置由浏览器本地保存，扩展本身不向第三方服务器上传配置。请仅在自己的校园网账号和授权环境中使用。

## 技术栈

- Chrome Extension Manifest V3
- 原生 JavaScript
- `chrome.storage.local`
- 网络认证页面自动化
